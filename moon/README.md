# 静海余光 · AFTERLIGHT

在主页仓库根目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000/moon/`。游戏需要 WebGL，全部运行资源随子页发布。

- WASD 移动，鼠标观察，Shift 加速，空格跳跃，E 交互，Esc 暂停。鼠标锁定不可用时可按住画面拖动，也可使用方向键观察。
- 触屏使用方向按钮移动，拖动月面观察，靠近采样点后按「交互」。

地形、岩石、设备和声音由代码生成。地球贴图来自 [NASA SVS Blue Marble](https://svs.gsfc.nasa.gov/2915/)，数据由 Reto Stöckli（NASA GSFC）和 NASA Earth Observatory 提供。Three.js 采用 MIT 许可证，见 [LICENSE](vendor/LICENSE)。
